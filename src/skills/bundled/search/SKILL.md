# search_stock

按股票名称或代码片段搜索 A 股，返回候选代码列表。

## 何时触发
- 用户只说了股票名称、没说代码时："比亚迪现在多少钱" → 先 search_stock("比亚迪") 拿到 002594，再调 get_stock_quote
- 用户问"有没有叫 xxx 的股票" / "xxx 的代码是多少"

## 参数
- `keyword`（必填）：股票名称、名称片段或代码前几位，如 "茅台"、"比亚"、"6005"

## 数据来源
优先走 Python 微服务 `/search`（AKShare 全量代码表 + 模糊匹配，见 `data-service/main.py`）；
微服务未启动时自动降级到东财搜索建议接口（`src/data/eastmoney.ts` 的 `search()`）。

## 注意
- 返回的是候选列表：**唯一匹配或名称完全一致时直接继续后续查询**；仅当多个候选都可能匹配时（如"平安"可能是平安银行/中国平安），把候选列给用户选，不要自己猜。
