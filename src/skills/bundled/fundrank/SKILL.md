# get_fund_rank

查询开放式基金排行榜（天天基金数据，与支付宝财富页同源），按近1年收益率降序，可按基金类型筛选。

## 何时触发
- "股票型基金排行" / "最近收益最好的债券基金" / "有哪些指数基金推荐看看排名" / "QDII 基金排名"

## 参数
- `type`（可选）：基金类型——全部 / 股票型 / 混合型 / 债券型 / 指数型 / QDII / FOF，默认全部。
- `limit`（可选）：返回条数，默认 10，最多 50。

## 数据来源
Python 微服务 `GET /funds/rank` → `ak.fund_open_fund_rank_em()`（天天基金开放式基金排行）。
场内 ETF（代码 51/15/16/58 等开头、像股票一样盘中实时交易）不在本技能范围。

## 备注
- 新基金的近1年等区间收益可能缺失（显示 —）。
- 输出仅供参考，不构成投资建议（SYSTEM_PROMPT 的免责声明规则自动覆盖）。
