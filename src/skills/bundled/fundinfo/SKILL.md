# get_fund_info

查询单只开放式基金详情：最新单位净值、日增长率、近期走势（近1周/近1月/近3月/近6月/近1年区间收益）。

## 何时触发
- "110022 这只基金怎么样" / "易方达消费行业基金净值多少" / "帮我看看某只基金最近表现"

## 参数
- `code`（必填）：6 位基金代码（如 110022），**或基金名称关键词**（如 "易方达消费"）——
  名称会先经基金搜索解析为代码；匹配多只有歧义时返回候选列表，由用户确认后再查。

## 数据来源
Python 微服务 `GET /funds/{code}` → `ak.fund_open_fund_info_em(indicator="单位净值走势")`（天天基金），
名称/类型来自 `ak.fund_name_em()` 全量基金代码表；搜索走 `GET /funds/search`。

## 备注
- 区间收益由单位净值历史按交易日回推计算（近1月≈22 个交易日），历史不足时不显示该区间。
- 输出仅供参考，不构成投资建议（SYSTEM_PROMPT 的免责声明规则自动覆盖）。
