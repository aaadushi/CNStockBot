# analyze_stock

AI 个股多维分析（F5-2）：一次性聚合某只 A 股的行情/估值、公司资料、资金流、技术指标、近两期财报、最新新闻
与资金流验货（F6-2：近期形态信号 × 日级资金流交叉验证的分档结论），
以结构化文本返回给 LLM，由 LLM 分维度生成客观解读。

## 何时触发
- "帮我分析一下比亚迪" / "600519 现在怎么样" / "全面评价一下宁德时代" / "这只股票能买吗"（红线：只客观解读，不给买卖建议）

## 参数
- `code`（必填）：6 位股票代码。若用户只说名称，先调 search_stock 解析代码（SYSTEM_PROMPT 已引导该流程）。

## 数据来源
全部复用既有 DataProvider 能力，无新数据源：
- 行情/估值：东财公开接口（失败自动降级腾讯）
- 公司资料 / 资金流 / 技术指标 / 财报 / 新闻 / 资金流验货：Python data-service（未启动时对应数据块标注"暂不可用"，其余块正常返回）
- 资金流验货走 data-service `/verify/{code}`（复用 F6-1 形态检测 + F3-4 资金流取数，缓存 1h）；验货分档（重点观察/中性/存疑）为透明阈值规则，口径见 docs/FEATURES.md 第 36 节

各数据块并发拉取、独立降级：单块失败只影响该块，不会拖垮整体。
返回内容仅为客观数据快照；多维度解读与免责声明由 SYSTEM_PROMPT 约束 LLM 在回复中完成。
