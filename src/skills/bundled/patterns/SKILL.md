# get_stock_patterns

K 线形态识别 + 历史成绩单（F6-1）：对一只 A 股做经典 K 线形态扫描（17 种：十字星、锤子线、
上吊线、看涨/看跌吞没、早晨/黄昏之星、乌云盖顶、刺透形态、红三兵、三只乌鸦、双底、双顶、
头肩底/顶、上升/下降三角形），返回近期出现的形态与每种形态的历史成绩单
（过去每次出现后 5/10/20 个交易日的上涨占比、平均涨跌幅、平均最大回撤）。

## 何时触发
- "600519 最近有没有出现什么形态" / "这只股票出现红三兵之后一般怎么走" / "帮我看看比亚迪的形态信号"
- 与 analyze_stock 的分工：本技能只回答形态与历史统计；用户要"全面分析/怎么看"时用 analyze_stock。

## 参数
- `code`（必填）：6 位股票代码。若用户只说名称，先调 search_stock 解析代码（SYSTEM_PROMPT 已引导该流程）。

## 数据来源
Python data-service `GET /patterns/{code}?days=750`：基于与 /history 同源的前复权日 K
（东财主源、新浪降级）纯本地计算，不新增外部依赖。微服务未启动时返回带启动提示的错误文本。

## 红线
返回的全部数字是**历史事实统计**（过去 N 次出现后的实际走势），不是对未来的预测。
转述给用户时必须保留"历史统计不代表未来表现"的口径说明与免责声明，
不得表述为买卖建议或涨跌预测；样本次数 < 5 的形态必须提示样本过少。
